# ナゾテン！ ～なぞって・たして・10の倍数～

5×5の数字を素早くなぞり、合計10・20・30・40を作って、
60秒間で高得点を目指す算数アクションパズルゲームです。
ラスト10秒は「ミリオン・フィーバー」が発動し、獲得得点が3倍になります。

本リポジトリは仕様書「ナゾテン！段階開発仕様書」のPhase 1を基に、
1人用スコアアタックを強化するPhase 2まで実装したものです。

## 遊び方

1. 「スコアアタック」を押してスタート。
2. 盤面の数字を上下左右につながる形で2〜5個なぞって、合計を10・20・30・40にする。
3. 40を作るとフォーティボーナスで得点2倍。
4. 制限時間は60秒。ラスト10秒は「ミリオン・フィーバー」で得点3倍。
   フィーバー中に40を作ると、フォーティボーナスと合わせて得点6倍。

## ローカルでの動作確認

このプロジェクトはビルド不要の静的HTML/CSS/JavaScriptですが、`js/*.js` はES Modules（`import`/`export`）を使っているため、
`index.html` を `file://` で直接開くとブラウザのCORS制限でモジュール読み込みに失敗します。必ず簡易HTTPサーバー経由で開いてください。

```bash
# Node.jsがある場合
npx serve nazoten

# Pythonがある場合
cd nazoten
python -m http.server 8080
```

起動後、表示されたURL（例: http://localhost:8080）をブラウザで開いてください。

GitHub Pagesなど静的Webホスティングにそのまま配置しても動作します。

## 実装範囲（Phase 1〜2）

- タイトル → 遊び方 → カウントダウン → 60秒プレイ → 結果画面の一連の流れ
- 5×5盤面（同じ数字は最大5個まで）、隣接マスのみをなぞれる操作
- 合計10・20・30・40の判定、フォーティボーナス（40は得点2倍）
- 消去後1秒での補充、補充待ち中も他マスの操作を継続可能
- 60秒制の1人用スコアアタック
- ラスト10秒のミリオン・フィーバーと得点3倍（自動発動・1プレイ1回）
- フォーティボーナスとの重複による最大6倍
- フィーバー専用の画面演出（金色盤面・開始オーバーレイ）・効果音・カウントダウン
- 通常タイム／フィーバータイムの得点内訳とプレイ記録（成功率・フィーバー中の成功回数など）
- なぞり音・成功音・40音・フィーバー音・失敗音・カウントダウン音・タイムアップ音・結果音（Web Audio合成音）
- 30秒版（Phase 1）と60秒＋フィーバー版（Phase 2）を分けたベストスコア保存（`localStorage` v1→v2移行、v1データは削除しない）
- 更新版チュートリアルのバージョン管理（`tutorialVersion`）
- 称号表示（60秒＋フィーバー版に合わせた新基準）

CPU対戦、1台2人対戦、ごちゃまぜバトル、オジャマ、じっくりモードなど将来拡張機能は未実装です。
