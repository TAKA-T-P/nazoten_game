# ナゾテン！ ～なぞって・たして・10の倍数～

1人でハイスコアを目指す「スコアアタック」、
強さ1～5・MAXのCPUと競う「CPUバトル」、
1台の端末を2人で挟んで対戦する「2人バトル」を遊べます。
CPUバトル・2人バトルはどちらも、別々の盤面で得点を競う「スコアバトル」と、
1つの盤面から数字を奪い合う「ごちゃまぜバトル」を選べます。

縦4×横4の数字を素早くなぞり、合計10・20・30・40を作って得点します。
ラスト10秒は「ミリオン・フィーバー」が発動し、獲得得点が3倍になります。
また、5マスで合計10を作ると「シルバー・フィーバー」が発動し、10秒間得点が2倍になります。

本リポジトリは、1人用・CPU対戦・1台2人対戦に加え、共有盤面のごちゃまぜバトルと
オジャマ（CPUバトル・2人バトルの両方に対応）を追加するPhase 6まで実装したものです。

## 遊び方

1. 「スコアアタック」を押してスタート。
2. 盤面の数字を上下左右につながる形で2〜5個なぞって、合計を10・20・30・40にする。
3. 40を作るとフォーティボーナスで+100点（フィーバー倍率の影響を受けない）。
4. 制限時間は60秒。ラスト10秒は「ミリオン・フィーバー」で得点が3倍になる。
5. 5マスで合計10を作ると「シルバー・フィーバー」が発動し、10秒間盤面が銀色になって得点が2倍になる
   （ミリオン・フィーバー中は発動せず、両方の条件を同時に満たした場合はミリオン・フィーバーが優先）。
6. 邪魔な数字は、素早く2回連続でタップ（ダブルタップ）すると得点なしで破壊できる。
   破壊した位置には1秒後に新しい数字が補充される。
7. 数字を短くタップすると選択状態になり、続けて別の数字をタップするとその2つの位置を
   入れかえられる。選択は、他の数字を長押ししたり、なぞり操作を始めたりすると解除される。

## CPUバトル

「強さ1」から「強さ5」、さらに最強の「MAX」まで、6段階のCPUと60秒間のスコア対決ができます。
「CPUバトル」を押すと、まず対戦形式（スコアバトル／ごちゃまぜバトル）とオジャマのON／OFF
（初期値はON）を選んでから、CPUの強さをスライドバーで選びます。

### スコアバトル

- プレイヤーとCPUは同じ数字の並びからスタートします。
- スマホ縦画面で1画面に収まるよう、両者の盤面は通常サイズの80%で表示されます。
- 開始後の消去・補充はそれぞれ独立しています（片方の操作がもう一方の盤面に影響しません）。
- プレイ中、正確なスコアは表示されません。
- 中央のバトルゲージ（点差を基準に正規化した割合）で、どちらが優勢かを確認できます。
- ラスト10秒はゲージが消え、両者の得点がミリオン・フィーバーで3倍になります。
- シルバー・フィーバー（5マスで合計10）はプレイヤー・CPUそれぞれ独立して発動し、発動した側の盤面だけが
  10秒間銀色になって得点2倍になります（ミリオン・フィーバー中は発動せず、優先度もミリオン・フィーバーが上）。
- タイムアップ後に両者のスコアと勝敗が発表されます。
- CPUは盤面を探索して経路を選び、実際になぞる演出をしたうえで得点を確定します。強さに応じて
  思考の速さ・見つけられる経路の長さ・最善手を選ぶ精度が変わり、わざと失敗したり、手詰まり時に
  得点なしで数字を破壊したりすることもあります。
- CPUレベルごとに、通算成績（勝敗数・自己最高得点など）を保存します。

### ごちゃまぜバトルCPU戦

- 1つの盤面をプレイヤーとCPUが共有し、同じマス・経路を早い者勝ちで奪い合います
  （仕組みは2人バトルのごちゃまぜバトルと共通）。
- 先に確定した側が得点・消去を獲得し、後から確定した側はペナルティなしで無効化されます。
- CPUが現在なぞっている最中のマスは、プレイヤーが入れかえ・破壊できません。
- 結果画面では称号・LVを表示しません（スコアバトルCPU戦との違い）。
- CPUレベルごとに、スコアバトルCPU戦とは別枠で通算成績を保存します。

### オジャマ（CPUバトル共通）

- オジャマをONにすると、CPUバトルでもスコアバトル・ごちゃまぜバトルの両方でオジャマが有効になります。
  経過20秒・40秒（残り40秒・20秒）で自動発動する仕組み・5種類の視覚効果（ターン・スモール・
  スマイル・メテオ・ハイド）は2人バトルのオジャマと共通です。
- CPUが勝っている側になった場合は、CPU自身が自動的にオジャマの対象になり、見た目の種類に
  かかわらず7秒間CPUの思考時間・なぞり操作時間が2倍になり、CPUの動きが遅くなります。

## 2人バトル

1台のスマートフォンやタブレットを2人で挟み、60秒間のスコアを競います。
「2人バトル」を押すと対戦形式（スコアバトル／ごちゃまぜバトル）とオジャマのON／OFFを
選ぶ画面が開きます。この設定はページ内でのみ記憶され、再読み込みすると
スコアバトル・オジャマONへ戻ります。

### スコアバトル

Phase 4から続く、それぞれ独立した盤面で得点を競う形式です。

- 画面下が青の1P、画面上が赤の2Pです。
- 2P側の盤面と表示は180度回転します（盤面のセル配置自体はP1・P2で共通で、CSSの回転
  だけで2P側から見て正しい向きになります）。
- 両者は同じ4×4の数字配置からスタートします。
- 開始後の消去・補充・入れかえはそれぞれ独立しています（片方の操作がもう一方の盤面に
  影響しません）。
- 2人が同時になぞり、破壊、数字入れかえを操作できます。Pointer
  Eventの入力コントローラーをP1・P2で別インスタンスにすることで、一方の指の動きが
  相手の盤面へ影響しません。
- プレイ中は正確な得点を表示せず、中央ゲージ（点差を基準に正規化した割合）で優勢を
  示します。
- シルバー・フィーバー（5マスで合計10）はプレイヤーごとに独立して発動し、発動した側の
  盤面だけが10秒間銀色になって得点2倍になります。
- シルバー・フィーバー中に再び5マスで10を作ると、倍率は2倍のまま重複させず、残り時間が
  10秒へ更新されます。
- ラスト10秒はゲージが消え、両者ともミリオン・フィーバーで得点3倍になります。ミリオン・
  フィーバー開始時、発動中のシルバー・フィーバーは両者とも即座に終了します。
- タイムアップ後に両者の得点・称号・勝敗・プレイ記録を、それぞれの向きから確認できる
  結果画面で発表します。
- 残り時間・SILVERバッジ・「もどる」ボタンは各プレイヤーの盤面の左側（2P側は反転しているため
  見た目上は右側）にまとめて表示し、盤面の位置がずれないようにしています。対戦中は
  「リトライ」を置かず、「もどる」でいつでもタイトルへ戻れます。
- 中央の優劣ゲージは「1P（バー）2P」の1行にまとめて表示し、2Pの文字だけ180度回転させています。

### ごちゃまぜバトル

P1・P2が同じ4×4盤面を共有し、数字を早い者勝ちで奪い合います。

- 相手がなぞっている数字は相手色（P1＝青、P2＝赤）でリアルタイム表示されます。同じマスを
  両者が選んでいる場合は、自分の選択（濃い塗り）と相手の選択（色つきリング）が重なって見えます。
- 同じ数字を2人が同時になぞることもできます。
- 先に正解を完成させた側が得点し、数字を共有盤面から消します（両方の盤面表示へ同時に反映）。
- 相手に先に数字を消された経路は、失敗扱いになりません（結果画面の「先に取られた回数」に記録）。
- 相手が現在なぞっている・入れかえ用に選んでいる数字は、入れかえ・破壊できません
  （確定の直前に再検証するため、選択タイミングが競合しても盤面は不整合になりません）。
- 消去・補充・入れかえ・破壊は両者の画面へ同期されます。
- シルバー・フィーバーは各プレイヤー別に発動し、ミリオン・フィーバーは両者共通です。
- 結果画面では得点・勝敗・プレイ記録を表示し、称号（LV表示）は表示しません。

## オジャマ

2人バトル（スコアバトル・ごちゃまぜバトルの両方）では、対戦前にオジャマのON／OFFを選べます
（初期値はON）。

- ボタン操作はありません。経過20秒・40秒（＝残り40秒・20秒）の時点で、その瞬間に
  勝っている側が自動的にオジャマの対象になります（同点の場合は発動しません）。1試合につき
  最大2回です。
- 対象になると7秒間、ランダムな視覚的オジャマ（ターン・スモール・スマイル・メテオ・ハイドの
  5種類から抽選）が発生します。
- ターン：対象プレイヤー側の数字だけを180度回転させます（盤面・当たり判定は変えません）。
- スモール：対象プレイヤー側の数字をマスごとにランダムな大きさへ縮小します（セルの大きさ・
  タッチ領域は変えません）。
- スマイル：対象プレイヤー側の盤面上を大きな絵文字が動き、数字の一部を隠します
  （`pointer-events: none`のためタッチ操作は妨げません）。
- メテオ：対象プレイヤー側の盤面の右上から左下へ複数の⭐が降り注ぎ、数字の一部を隠します
  （こちらも`pointer-events: none`でタッチ操作は妨げません）。
- ハイド：対象プレイヤー側の数式表示（「3+3+4=10」など）を黒い矩形で完全に隠します。
- オジャマを受けた側には、残り時間表示のすぐ下に「オジャマ「メテオ」」のように受けた種類を
  7秒間表示します。
- オジャマは表示だけを変え、数字・座標・操作判定には一切影響しません。
- ラスト10秒のミリオン・フィーバーが始まると、進行中のオジャマは即座に解除されます
  （重複しません）。

## 得点計算

```text
得点 = 合計 × なぞったマス数 × フィーバー倍率 ＋ フォーティボーナス
```

- フォーティボーナス：合計が40のときだけ+100点。フィーバー倍率の影響を受けない。
- フィーバー倍率：「ミリオン・フィーバー」中は3倍、「シルバー・フィーバー」中は2倍、それ以外は1倍。
- 倍率確定のタイミングは、指を離して成功が確定した瞬間のフェーズ。
- シルバー・フィーバー（5マスで合計10）は、ミリオン・フィーバー中でないときにだけ発動し、
  10秒間得点が2倍になる。発動のトリガーとなった手自体は発動前の判定のため通常倍率で加点される。
  ミリオン・フィーバーとは同時発動せず、両方の条件を満たした場合はミリオン・フィーバーが優先される。

| 条件 | 計算式 | 得点 |
| --- | --- | ---: |
| 通常時に3→7（合計10・2マス） | 10 × 2 + 0 | 20点 |
| ミリオン・フィーバー中に3→7 | 10 × 2 × 3 + 0 | 60点 |
| シルバー・フィーバー中に3→7 | 10 × 2 × 2 + 0 | 40点 |
| 通常時に4マスで合計30 | 30 × 4 + 0 | 120点 |
| ミリオン・フィーバー中に4マスで合計30 | 30 × 4 × 3 + 0 | 360点 |
| 通常時に5マスで合計40 | 40 × 5 + 100 | 300点 |
| ミリオン・フィーバー中に5マスで合計40 | 40 × 5 × 3 + 100 | 700点 |

## サウンド

タイトル画面の「◀ [モード名] ▶」で、次の8項目を前後に切り替えられます（矢印ボタンの位置は
表示テキストの長さが変わっても動きません）。

| 表示 | 内容 |
| --- | --- |
| 効果音のみ | なぞり音・成功音などの効果音のみ。BGMは流れない |
| BGMランダム | BGM＋効果音。プレイ開始のたびに5曲からランダムに1曲再生 |
| BGM1〜BGM5 | BGM＋効果音。対応する1曲を固定で再生 |
| 音なし | すべての音を鳴らさない |

起動するたびに（再読み込み・再起動を含む）必ず「効果音のみ」から始まります。切り替えた設定は
その場では`localStorage`に保存されますが、次回起動時には引き継がれず「効果音のみ」にリセットされます。

### BGM

`assets/bgm/`にある5曲を、選んだサウンドモードに応じてランダムまたは固定で再生します。曲ごとに
長さが微妙に異なるため、曲の盛り上がりとゲーム進行が噛み合うよう、曲ごとに再生開始タイミングを
変えています。

| 曲 | 再生開始タイミング |
| --- | --- |
| BGM01_焦りは禁物 | カウントダウン「3」表示と同時 |
| BGM02_てんやわんやなお嬢様 | カウントダウン「2」表示と同時 |
| BGM03_和風ロックBGM | カウントダウン「1」表示と同時 |
| BGM04_ColdHeart | 「START!」表示と同時 |
| BGM05_達成！ | ゲーム開始（START!）から3秒後（残り57秒） |

BGMはタイムアップ時、および「もどる」でタイトルに戻ったときに停止します。

## ローカルでの動作確認

このプロジェクトはビルド不要の静的HTML/CSS/JavaScriptですが、`js/*.js` はES Modules（`import`/`export`）を使っているため、
`index.html` を `file://` で直接開くとブラウザのCORS制限でモジュール読み込みに失敗します。必ず簡易HTTPサーバー経由で開いてください。

```bash
# Node.jsがある場合
npx serve nazoten

# Pythonがある場合
cd nazoten
python -m http.server 8080
```

起動後、表示されたURL（例: http://localhost:8080）をブラウザで開いてください。

GitHub Pagesなど静的Webホスティングにそのまま配置しても動作します。
